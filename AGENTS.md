# AGENTS.md — project building rules

This repository is the organizer-controlled Model_tester benchmark and public results showcase. Contestant models must never receive repository access during blind runs.

Before changing the project, read this file, `PROJECT.md`, and the nearest folder `CONTEXT.md`. Keep all maintained folders documented. Visual source folders also require `DESIGN.md` and a genuine current `SCREENSHOT.png`; do not fabricate evidence.

Preserve the append-only submission contract. Never overwrite an existing submission. Do not weaken ZIP validation, expose private run logs, or give contestant agents access to this repository. Validate artifacts before publication and keep blind-run isolation separate from organizer publication.

After changes, run relevant validation workflows and inspect GitHub Actions results. Use version-aware GitHub edits, preserve unrelated content, and update the affected context notes.
