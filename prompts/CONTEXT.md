# Context: prompts

## Purpose
Holds the 30 independent Markdown challenges used to compare model software-building capability.

## Key files
- `01-*.md` through `30-*.md` — standalone challenge prompts.
- `README.md` — prompt index, blind-run guidance, artifact contract and upload instructions.

## Connections
Each prompt produces an artifact that is uploaded to `incoming/` and processed into `submissions/` by the organizer workflow.

## Change & verify
Preserve numbering, filenames and the shared ZIP contract. Keep creative direction open while retaining measurable acceptance criteria. Update the README whenever the submission process changes.
